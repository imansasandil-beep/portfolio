Designing a Database for a Grocery Service

October 23, 2025

This was one of my most in-depth projects: designing a complete conceptual database (EERD) for 'Foodz@Yourz,' a complex online grocery delivery service. I started by analyzing a detailed brief that outlined all the business rules.

The key challenge was modeling the complex relationships. This included store-specific product pricing, handling the full order lifecycle (from basket to payment, collection, and delivery), and mapping the interactions between members, staff (drivers, workers), and vehicles. The result is a comprehensive EERD that maps all entities and relationships, ensuring a solid and logical foundation for the application's backend.

Building a Desktop Budgeting App

September 15, 2025

Building a real-time stock ticker application was a great way to dive deep into concurrent programming. I started by designing a clear architecture to handle high-volume data streams without performance bottlenecks. The core challenge was implementing thread-safe data updates and ensuring the GUI remained responsive during heavy processing.

I used Java's Executor Framework and Callable/Future interfaces to manage a pool of worker threads responsible for fetching and processing stock data asynchronously. Swing was used for the graphical user interface, and synchronized blocks and Concurrent Collections were critical for managing shared data access. The final application provides a fast, reliable, and continuously updating display.
